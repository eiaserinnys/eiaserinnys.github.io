에이전트가 MCP로 읽고 쓰며, 사람은 웹 대시보드에서 트리와 문서를 확인하는 지식 베이스다.

GitHub
01 대시보드 사람은 트리, 문서, 카드 세 칸에서 에이전트가 고친 내용을 확인한다. 3칸 대시보드 화면
02 카드와 자리 카드 하나를 여러 노드에서 참조해, 한 번 고치면 연결된 모든 노드에 반영된다. 1 → N 카드와 자리
03 서브트리 컴파일 하위 트리를 지정한 깊이까지 문서 한 편으로 합쳐 에이전트에게 전달한다. depth 컴파일 깊이
04 MCP 도구 에이전트는 15개 MCP 도구로 카드 생성과 트리 수정을 한 트랜잭션으로 처리한다. 15 MCP 도구
05 검색 BM25 전문 검색으로 본문을 찾고, 검색 범위는 특정 하위 트리로 한정할 수 있다. BM25 전문 검색
06 설치 개발 환경에서는 SQLite 파일 하나로 시작하고, 운영 서버에서는 PostgreSQL로 전환한다. MIT 라이선스
로컬과 단일 서버 SQLite 별도 DB 서버 없이 단일 파일로 동작하며 FTS5 전문 검색을 포함한다.
운영 서버 PostgreSQL 스키마와 MCP 도구는 SQLite 판과 같고, 데이터베이스만 PostgreSQL로 바꿔 연결한다.

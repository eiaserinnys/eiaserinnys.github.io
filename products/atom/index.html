에이전트가 MCP로 쓰고, 사람은 웹 대시보드에서 확인하는 지식 베이스다.

GitHub
01 대시보드 사람은 트리와 문서, 카드를 나란히 놓고 에이전트가 고친 내용을 본다. 실시간 변경 반영
02 심링크 카드 하나를 트리 여러 곳에 두고, 한 번 고치면 모든 곳에 반영된다. 1 → N 원본 → 위치
03 서브트리 컴파일 하위 트리를 원하는 깊이까지 엮어 문서 한 편으로 에이전트에게 준다. 1회 도구 호출
04 MCP 에이전트는 카드와 트리를 MCP로 직접 다루고, 여러 변경은 batch_op 한 번으로 묶는다. 15 도구
05 검색 본문 전체를 찾되, 검색 범위를 하위 트리 하나로 한정할 수 있다. BM25 순위 방식
06 설치 처음엔 DB 서버 없이 띄우고, 운영 서버에서는 PostgreSQL로 옮긴다. 1 SQLite 파일
로컬과 단일 서버 SQLite 단일 파일, FTS5 포함
